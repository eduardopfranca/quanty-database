# Retrospectives

Per-session, backward-looking records. One file per session, created at the end of the session, never edited after that.

**Naming:** `YYYY-MM-DD-slug.md` (e.g. `2026-05-28-remove-supabase-and-fix-cooldown.md`).

## How this differs from `docs/handoff.md`

| | `handoff.md` | `retrospectives/` |
|---|---|---|
| Written | End of every session (overwrites previous) | End of every session (new file, never overwritten) |
| Purpose | Resume the project — current state + next step | Understand what happened in a specific session |
| Audience | The next session's assistant (or Eduardo) | Debugging, context, post-mortems |

Use `handoff.md` to continue work. Use retrospectives to understand *why* a decision was made or reversed.
